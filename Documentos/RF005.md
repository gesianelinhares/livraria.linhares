# Reserva de Livros
**COMO** Leitor, <br>
**QUERO** solicitar a reserva de um livro que já está emprestado <br>
**PARA** garantir que serei o próximo a retirá-lo assim que ele for devolvido. <br>

**Critérios de Aceitação:**
- O sistema deve permitir a reserva apenas para livros que tenham todos os exemplares ocupados.
- Deve ser mantida uma fila de espera cronológica para cada título.
- O sistema deve notificar o próximo leitor da fila assim que o livro for devolvido no balcão.
- A reserva deve expirar automaticamente se o livro não for retirado em até 48 horas após a devolução.
