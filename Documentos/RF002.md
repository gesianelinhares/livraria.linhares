# Cadastro de Leitores
**COMO** Operador do Sistema, <br>
**QUERO** cadastrar os usuários da biblioteca <br>
**PARA** que seja possível realizar o controle de empréstimos e identificar os responsáveis pelos livros. <br>

**Critérios de Aceitação:**
- Deve ser possível registrar nome completo, CPF, comprovante de residência e contato.
- O sistema deve gerar um número de matrícula único para cada leitor.
- O sistema deve impedir o cadastro de usuários com CPF já existente na base de dados.
- Deve ser possível suspender o cadastro de usuários em débito com a biblioteca.
