# Cadastro de Acervo (Livros)
**COMO** Bibliotecário, <br>
**QUERO** cadastrar os livros e exemplares disponíveis no acervo <br>
**PARA** que o catálogo esteja sempre atualizado para consulta dos cidadãos. <br>

**Critérios de Aceitação:**
- Deve ser possível informar título, autor, editora, ISBN e categoria (gênero).
- O sistema deve permitir registrar a quantidade total de exemplares e o número de série de cada um.
- O sistema deve validar o código ISBN para evitar duplicidade de títulos.
- Deve ser possível atualizar o estado de conservação do livro (ex: novo, desgastado, em manutenção).
