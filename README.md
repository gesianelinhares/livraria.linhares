# Contexto do Projeto e Problema Resolvido
A Biblioteca Municipal Linhares solicitou o desenvolvimento de uma solução tecnológica para modernizar a gestão de seu acervo público. O objetivo é substituir registros manuais por um sistema centralizado, que permita à administração catalogar títulos, gerenciar usuários e controlar o fluxo de empréstimos e devoluções de forma ágil.

O projeto Linhares Leitura resolve o problema da dificuldade de acesso à informação e do controle de acervo físico. Através desta plataforma, é possível acompanhar o ciclo de circulação de cada obra — da reserva à devolução — transformando dados brutos em indicadores de leitura e garantindo que o patrimônio cultural seja gerido com total transparência e eficiência.
