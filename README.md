# livraria.linhares
O projeto visa modernizar a gestão da Livraria Linhares, centralizando o acervo e as vendas em uma plataforma integrada. Ele resolve a dificuldade de controle manual de estoque, permitindo que a loja gerencie títulos, autores e pedidos de forma digital, transformando registros brutos em relatórios ágeis para uma melhor experiência do leitor.
